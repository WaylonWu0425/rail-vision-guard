- 权重SHA256：`69747c4762e13194385e7c3111b728bae42fcadfbefc21a29f4b3a8e2640a33e`。原版副本与当前权重哈希一致，加载前检查。
- 固定参数：整图、imgsz=640、conf=0.25、NMS IoU=0.7、CPU。对应原版直接检测脚本的默认推理方式，不复制 CamVueScan.py 的640×480预缩放、每2秒推理、conf=0.4和定时测试告警。不同原脚本并非同一配置，不能笼统宣称逐项复现所有脚本。

## 使用

1. 在项目根目录运行 `pwsh -NoProfile -File .\start_demo.ps1 -SkipModelCheck`。这里使用新版PowerShell，避免原启动脚本的UTF-8在旧版PowerShell中的解析问题。
2. 正常登录，在左侧选择“原版人车识别”，或从“智能检测”顶部进入。
3. 选择图片、本地视频、本机摄像头或网络摄像头，点击“开始识别”。
4. 查看人车检测框、类别、置信度、当前帧计数、像素坐标和处理时间。
5. 本地视频可以暂停、继续、停止。切换路由会请求停止任务；实时摄像头任务失联120秒自动停止。全服务同一时间只运行一个原版任务，拒绝重复排队。

仅启动该识别服务也可双击 `scan/Detection/启动原版识别.cmd`。它不会启动Java或主检测任务。API仅监听127.0.0.1:5002，只允许本机与8080/8082的本机页面调用；写请求需要页面会话凭证。这是本地演示配置，不是公网鉴权方案。

8080目前被另一项目GeoServer容器占用；没有停止或修改该容器。本轮系统前端使用 **http://localhost:8082/**，页面地址为 **http://localhost:8082/originalRecognition**。启动脚本会识别网页标题，避免把其他项目误认为本系统；遇到8080冲突时改用8082。

## 文件与资源

- 图片支持JPG/PNG/WebP/BMP，最大16 MB、1600万像素，处理后仅保留当前结果在内存。
- 视频支持MP4/AVI/MOV/MKV/WebM，实际编码须能由OpenCV解码，最大512 MB。上传只到本机 `.original-inputs`，正常完成、失败、停止后删除临时副本，原视频不改动。
- 进程被强制终止时，临时副本可能残留；本轮不自动递归清理历史文件。遇到磁盘空间不足应先停止任务并人工核对临时文件。
- 视频顺序处理每个可解码帧，不通过抽帧冒充全帧识别；计算慢时检测播放变慢。浏览器轮询展示最近结果，不保证显示每一帧，没有加入原版不存在的任意拖动定位功能。
- 本机摄像头是运行Python服务的电脑的摄像头，编号0—9；网络摄像头只允许选择数据库中已配置设备，不接受任意RTSP地址。摄像头凭据不返回浏览器。
- 处理耗时包含推理及框绘制，不等于摄像头端到端延迟。平均完成频率按实际完成次数/经过时间计算，不用耗时倒数冒充FPS，也不是正式性能基准。

1. `python -m unittest test_original_recognition -v`：16项通过。涵盖图片结果、逐帧调用、暂停/继续/停止、并发拒绝、失败输入、临时文件删除、资源释放、本机来源校验、会话凭证和凭据不外泄。摄像头测试使用注入的测试采集器，不是硬件实测。
2. 真实模型接口测试：一张铁路照片、`环境监控.avi` 共68帧完整处理完成，返回可解码JPEG；输入和模型哈希前后不变，线程池关闭、采集释放、视频临时副本删除。
3. 前端生产构建成功，有现有第三方资源包体积和样式弃用告警；未安装新依赖。
4. Edge无头浏览器真实登录→新页面→上传图片/AVI→实际best.pt推理→图像和计数渲染；视频暂停/继续、停止完成，页面无运行时异常。图片浏览器样例采用已有合成演示图，只验证链路，不计入真实场景效果评价。
5. USB/RTSP真实摄像头尚未验收：已接入代码、验证界面和失败路径，但没有擅自打开硬件。需要用户接入设备后确认。

## 不能声称的结论

框与计数都是模型预测，不能直接当作真值。真实铁路视频末帧有2个person预测框，但截图中存在疑似背景误检，不能写为“成功发现2名人员”。测试照片输出0个目标，也不能据此断言画面无人。上述验证只说明输入到结果链路可用，没有生成新的准确率、误报率或泛化结论。

原版定时写入的“实时告警”“启动测试记录”未接入。没有恢复原版安全缺陷，没有修改现有模型默认策略、已有标注、录像索引或告警记录。该工作不解决此前离线候选跟踪方案的内存增长预警，不应合并宣称该问题已修复。

## 停用与回退

### 2026-10-26 页面布局修订

仅修改前端界面和浏览器回归脚本，未修改原版权重、推理参数或识别服务：

- 修复路由页在父级Flex容器中未横向伸展的问题。空态与有素材时都填满工作区，右侧操作栏370像素，较窄桌面330/300像素。
- 精简顶部，将输入、概况、可折叠参数分层；上传入口可键盘操作，显示文件名和大小。
- 区分未选择、待开始、运行、暂停、完成、失败。未推理前计数为“—”，不显示“未检出”表格；更换素材立即清除旧预测。
- 选图可预览原图，浏览器支持的视频可原始播放预览。AVI等浏览器不支持的格式明确提示后仍允许服务识别。Object URL更换及离页时释放。
- 保持素材比例，使用contain不裁剪；为控制画面高度，比例不匹配时允许画面周围留边，不以拉伸或裁剪换取填满。
- 浏览器验证覆盖1280×720、1366×768、1860×980、1920×1080空态满宽与无横向溢出，及真实识别、暂停、继续、停止和离页释放。记录和截图单独保存到 `docs/original-recognition-ui-20261026/`，不覆盖首次接入记录。
- 生产构建成功，仍有既有第三方包体积与样式弃用提示。未进行新的准确率评价或摄像头硬件测试。

停止5002端口的本次原版识别服务即可停止新能力；已运行任务先点“停止识别”，等待结束。原有智能检测仍走5000端口，不依赖本模块。原版目录保留不动，无数据库迁移或需要恢复的业务数据。
