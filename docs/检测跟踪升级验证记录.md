- 同一跟踪目标持续停留只生成一次区域事件，离开并以新轨迹进入后才能再次触发；
- 页面显示推理耗时、推理 FPS、视频 FPS 和当前跟踪数；
- 异物受控原型增加亮度归一、机位位移检查及人车检测框遮罩；
- GPU 环境使用验证标记启用，失败时保留 CPU 回退。
