# 视界巡警单枪机演示说明

## 真实能力边界

- 唯一实机为大华固定枪机 DH-IPC-HFW4443T-AS-P；它负责采集画面，不负责在设备侧运行异物识别。
- YOLO 推理由本机 `scan/Detection/detection_service.py` 完成；当前模型类别仅为 `person` 与 `car`。
- 不要启动历史脚本 `scan/Detection/CamVueScan.py`；它包含早期测试用途的定时告警逻辑，不属于本次真实检测演示链路。
- “异物遗留”是固定机位、固定光照、固定显示设备下的基线差分原型，不应描述为通用异物识别或现场部署效果。
- 系统默认把检测服务绑定到 `127.0.0.1`。浏览器直连设备的凭据配置仅适用于本地演示，不得按公网部署方案宣传。

## 演示顺序

1. 启动 MySQL、Java 后端、YOLO 服务和前端，登录后进入“YOLO智能检测”。健康标签必须显示模型和数据库均已就绪。
2. 选择枪机，点击“启动检测”，等待状态显示“检测中”。未启动时系统不会连接 RTSP、推理或产生告警；点击“停止检测”会释放该任务。
3. 使用固定摆位：摄像头正对显示器。依次展示空场景、人员进入、车辆进入。人员入侵需先画定并保存警戒区域，再按设定停留时间观察告警与截图。
4. 异物演示前先显示空场景并“设置当前空场景为基准”；保持机位和亮度不动，放入静止物体并等待设定时间。改变机位或亮度后先清除并重建基准。
5. 在实时预览页，事件前点击“开始录制”，事件后点击“停止录制”。上传成功后，检测页告警的“关联录像”会打开覆盖该告警时刻的回放；上传失败时浏览器会下载本地文件，不能说录像已入库。
