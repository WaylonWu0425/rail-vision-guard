# 视界巡警系统整体优化路线图

更新时间：2026-09-27。范围为现有单台大华固定枪机的本地比赛演示，不代表已通过现场部署验收。

## 已完成的第一轮修整

- 登录页移除预填的演示账户和明文密码显示，仅可选记住账户；账户、密码、邮箱验证码和注册凭据改由 POST 请求体传递，避免出现在 URL 中。
- 移除账户登录接口错误配置的“先登录”注解；退出登录时无论远端请求是否成功，均清除本地会话。
- 恢复受保护页面的前端路由守卫，并在会话失效时清理本地登录状态。注意：前端路由守卫不替代后端鉴权。
- 首页轮询只在首页运行；离开时关闭计时器、状态 WebSocket 和图表实例。摄像头状态更新同时处理单条或列表消息。
- 修正摄像头管理页对单条状态消息的处理；导航菜单使用当前路由高亮，并清理一个不存在的任务接口导入。
- 竞赛演示的登录页采用响应式布局；告警页的小规模摄像头筛选改用普通下拉，避免不必要的虚拟选择器宽度测量；全局补充字体、主色和键盘焦点样式。
- 移除无效的全局 ECharts 插件注册，业务页面按路由分包加载。
- 播放器 SDK 改为首次打开实时预览时再加载；加载失败时回退并提示，不让登录页预先请求播放器脚本。
- 移除页面切换时新旧页面并存的 0.5 秒淡入淡出；统计页卸载时释放六个图表和窗口监听；录像页不再加载未使用的 HLS、Video.js 与重复图标脚本。登录后空闲时预取实时预览、检测、告警、录像和摄像头管理页。
- 第二阶段界面已将主工作区、侧栏和录像页改为基于可用高度的内部滚动布局，避免嵌套页面使用 `100vh` 导致裁切；实时预览、智能检测、设备管理和告警页补充空态、失败提示及窄屏布局。固定枪机在预览页保持“数字缩放”表述，不展示机械控制。
- 第三阶段将录像页的图标统一切换为项目内置的 Element Plus 图标，并移除 Font Awesome、HLS.js、Video.js 的遗留外部加载逻辑；录像播放仍使用现有后端 Range 流接口，未改变录像存储与上传流程。
- 第四阶段已增加 `start_demo.ps1` 启动前检查，覆盖 Python/Node/npm、模型、前端依赖、C/D 盘空间、录像目录和三个本地服务；发现前端未运行时脚本会启动 Vue 开发服务。摄像头状态 WebSocket 改为页面共享订阅并经前端 `/ws` 代理连接，恢复后读取摄像头快照。
- 录像列表读取失败会向前端返回明确错误，回放端点改为 `StreamingResponseBody` 分块输出，上传端同步校验文件类型和 200 MB 限制。录像页增加就地重试，智能检测告警区分实时模型事件与受控异物原型，侧栏按“预览→检测→告警→回放”排列比赛演示主流程。
- 检测服务已接入每摄像头独立 ByteTrack，事件记录增加跟踪 ID、规则类型、首次出现／触发时间、持续时长、模型版本和运行设备；人员与车辆可分别配置区域规则、停留阈值及冷却时间，同一目标持续停留不重复刷屏。
- 智能检测页显示实际运行设备、推理耗时／FPS、跟踪目标数和模型版本；受控异物基线增加亮度归一、场景位移检查及人车框遮罩，机位明显改变时提示重新采集基准。
- GPU 安装脚本已改为失败即停止，并以 `.gpu-ready` 作为启用条件。当前健康检查实测仍为 CPU；GPU 加速尚未完成，不能在材料中写成已启用。

## 下一阶段优先级与验收

| 优先级 | 工作 | 完成条件 |
| --- | --- | --- |
| P0 | 单枪机端到端演示回归 | 实机完成预览→人工启动检测→一次告警及截图→手动录像→告警定位录像→回放拖动；记录原始画面、阈值、耗时和失败截图。 |
| P0 | 摄像头离线与服务故障恢复 | 拔网线、停止识别服务、重启后端后，页面显示可操作提示；恢复后状态、预览与检测任务不重复。 |
| P0 | 告警真实性与数据隔离 | 测试脚本数据、历史演示数据和本次实时检测记录清楚区分；不能把人工构造记录作为模型识别结果。 |
| P1 | 摄像头状态连接收敛 | 三个页面共用可配置的 WebSocket 地址、重连与卸载逻辑；断线后重新获取摄像头快照。 |
| P1 | 录像索引与失败提示 | 上传成功才标记“已入库”；上传失败保留本地文件；历史无元数据录像不猜摄像头、时间或时长。 |
| P1 | 性能优化 | 用路由分包后的构建产物做首屏对比；针对仍较大的 Element Plus、ECharts、播放器资源按需加载。 |
| P1 | 统一监控工作台视觉 | 在预览、检测、告警、录像四页统一状态颜色、筛选方式、空状态、错误提示和移动端布局；实机截图人工检查。 |
| P2 | 密码存储升级 | 设计 Base64 存量账户的安全迁移与回滚方案，迁移至不可逆带盐密码哈希；覆盖注册、登录、修改密码测试。 |
| P2 | 设备凭据与 WebSocket 安全 | 改为后端代理设备访问，浏览器不再取得摄像头密码；WebSocket 增加会话鉴权及允许来源约束。 |
| P2 | 模型能力扩展 | 人车检测继续按现有 YOLO 能力表述；异物仅为固定机位基线对比原型。新模型训练、标注、独立测试后再宣传类别识别效果。 |

## 当前验证边界

- `npm run build` 通过，但仍有资源体积和旧 `::v-deep` 语法警告；按路由分包后入口 JS/CSS 构建产物合计由约 2.8 MiB 降到约 1.57 MiB，不等于用户实测加载时间。
- `mvn test -q` 通过；现有测试主要验证 Spring 上下文可启动，不等于登录、录像、告警和实机 30 分钟回归均已通过。
- 应用内浏览器自动检查接口未能连接到浏览器会话；改用本机无痕无头浏览器检查了登录页桌面截图、当前服务输出，以及未登录访问实时预览时返回登录页。此项不等于凭据登录、摄像头和录像全流程已验收。
- 固定枪机不具备机械云台、光学变焦、聚焦和光圈控制；数字缩放需始终标明为浏览器画面操作。服务器识别能力不能表述成摄像头内置能力。
