# 车辆与车钩识别：本机第一阶段

模型来自项目目录 `模型/best12_20.param` 与 `模型/best12_20.bin`。识别服务在 `127.0.0.1:5003` 运行，只提供图片及当前视频帧推理，不写入现有告警和任务数据库。

## 启动

本机使用 Python 3.12。在本目录创建隔离依赖目录：

```powershell
py -3.12 -m pip install --target .ncnn-runtime ncnn opencv-python-headless imageio-ffmpeg
```

然后运行 `启动车钩识别.cmd`。在前端的“作业感知”页面选择图片或视频，视频暂停到目标帧后点击“识别当前画面”。服务健康检查地址是 `http://127.0.0.1:5003/health`。

旧视频使用 MPEG-4 Part 2（如 `FMP4`）时，浏览器可能只能看到 0:00 灰屏。页面收到播放错误后，会将原视频发送到本机 `127.0.0.1:5003/transcode`，临时转换为 H.264 MP4 再播放。源文件保持不变；服务处理完请求即清除临时文件。最大输入 512 MB，转换超时 180 秒；较长视频建议先截取片段。视频内容只经过本机环回接口。

## 当前数据边界

- 输出类别表按 APK 中相邻类别字符串的顺序配置：`freight car`、`coupler_far`、`couplers`、`coupler_near`。需由模型训练者复核类别编号及预处理方式。
- 当前实现采用 640 输入、居中补边、DFL 解码、置信度 0.45、按类别 NMS IoU 0.5。它是桌面端适配实现，尚未证明与安卓 APK 逐帧完全一致。
- 图片识别结果是模型预测，需人工复核。没有相机标定及安卓传感器时间记录时不显示距离和连挂结论。
- 页面“保存当前帧”产生的是从本地视频截取的原始画面，不代表识别证据。关闭或切换素材会释放这些临时帧；需要保留时请先下载。
